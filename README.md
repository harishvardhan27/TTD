# Low-Rank Factorization and INT8 Quantization of Vision Transformers on CPU

A reproducible study of post-training compression for Vision Transformers on a
laptop CPU: weight SVD vs activation-whitened SVD, Tensor-Train, budgeted rank
allocation, dynamic INT8 (PyTorch and ONNX Runtime), and distillation, with
paired statistical tests on a held-out, contamination-checked test set.

The project began as a Tensor-Train compression project. Its own audit
([`RESEARCH_AUDIT.md`](RESEARCH_AUDIT.md)) found that earlier headline numbers
were measured on training-provenance images and on a mis-implemented rank
search; those documents are preserved in [`docs/history/`](docs/history/)
and are **not** results.

## Installation

Tested with Python 3.10, PyTorch 2.11 (CPU), timm 1.0.31, ONNX Runtime 1.23 on Windows 11.

```bash
pip install -e ".[vision,deploy,dev]"     # + "kernels" for the C++ extension
pytest                                     # ~30 s, no downloads except timm configs
```

## Data (no ImageNet account needed)

```bash
mkdir -p data && cd data
# training-side: calibration + distillation
curl -L https://s3.amazonaws.com/fast-ai-imageclas/imagenette2-320.tgz | tar -xz
git clone --depth 1 https://github.com/EliSchwartz/imagenet-sample-images.git
# evaluation: ImageNetV2 matched-frequency (the HF file is an uncompressed tar)
mkdir imagenetv2 && cd imagenetv2
curl -L -o v2.tar https://huggingface.co/datasets/vaishaal/ImageNetV2/resolve/main/imagenetv2-matched-frequency.tar.gz
tar -xf v2.tar && cd ../..
python -c "from ttcompress import data as D; [D.write_manifest(s) for s in ('v2_dev','v2_test','imagenette_train','imagenette_val','imagenet_sample')]"
```

Compare the manifest digests with `data/manifests/*.json` (`sha256` field) to
confirm identical files and splits.

## Running experiments

```bash
# hyperparameter / question studies on ImageNetV2-dev (selection only)
python experiments/run.py --config configs/deit_small.yaml --suite dev  --split v2_dev
# final grid on ImageNetV2-test (hyperparameters frozen in the config)
python experiments/run.py --config configs/deit_small.yaml --suite core --split v2_test
python experiments/run.py --config configs/vit_base.yaml   --suite core --split v2_test
# distillation (selection on dev, one final test evaluation)
python experiments/distill_run.py --config configs/deit_small.yaml --student data_attn+mlp_b0.6 --tag final --final ...
# CPU benchmarks (requires AC power)
python experiments/benchmark.py --config configs/deit_small.yaml --what model --backend torch
python experiments/benchmark.py --config configs/deit_small.yaml --what model --backend ort
python experiments/benchmark.py --what layers
# tables and figures
python experiments/analyze.py --model deit_small --split v2_test --suite core
```

Runs are resumable (finished variants are skipped) and never overwrite results.
Every result JSON records the git commit, config hash, checkpoint SHA-256,
split-manifest SHA-256, software versions, thread count and power state.

## Hardware used

AMD Ryzen 7 7730U (Zen 3, 8C/16T, AVX2+FMA, no AVX-512/VNNI), 15.3 GB RAM,
integrated Radeon (unused). No CUDA device: the CUDA kernel in
`THEORY_VERIFY/` has never been compiled and no GPU claim is made.
